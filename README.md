## 🧠 `07` — CORE IMPLEMENTATION

<div align="center">

### 💙 THE LOGIC BEHIND THE APPLICATION

The project uses Python, Pandas and NumPy to load, process and analyze
expense records stored in a CSV file.

</div>

### 📂 DATA LOADING & CLEANING

The application loads the expense dataset from `expenses.csv` and prepares
the date and amount fields for analysis.

| ⚙️ **PROCESS** | 📝 **IMPLEMENTATION** |
|:---|:---|
| 📄 **Load Data** | Read expense records from `expenses.csv` |
| 📅 **Date Handling** | Convert date values into a usable format |
| 💰 **Amount Handling** | Convert expense amounts into numeric values |
| 🧹 **Cleaning** | Remove invalid records before analysis |

### 📊 EXPENSE ANALYSIS

The application processes the cleaned dataset to calculate useful spending
information.

| 📈 **ANALYSIS** | 🎯 **PURPOSE** |
|:---|:---|
| 💰 **Total Expense** | Calculate overall spending |
| 📊 **Average Expense** | Calculate average spending per record |
| 🗂️ **Category-wise Expense** | Compare spending across categories |
| 🔎 **Filtering** | Find records belonging to a selected category |
| 🧾 **Expense Count** | Determine the number of recorded expenses |

### 🎨 VISUALIZATION ENGINE

The processed data is passed to Matplotlib to generate four visualizations:

**🟦 Bar Chart** → Category comparison  
**📈 Line Chart** → Expense trend  
**🌸 Pie Chart** → Category distribution  
**📊 Histogram** → Expense frequency
